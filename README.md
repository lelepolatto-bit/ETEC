## Como executar

Com Python 3.10 ou superior instalado, clone este repositório:

```bash
git clone https://github.com/lelepolatto-bit/ETEC.git
cd ETEC
```

Entre na subpasta da atividade desejada e execute seu arquivo principal. Por exemplo:

```bash
cd consumo-agua
python3 app.py
```

Cada subpasta possui seu próprio README. Os projetos copiados mantêm suas instruções e links para os repositórios separados, com os READMEs ajustados para remover emojis.
