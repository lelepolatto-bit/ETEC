# Atividade 10 de DSI — Cálculo de notas

Esta atividade tem como objetivo calcular a média das notas de um aluno e
informar se ele foi aprovado ou reprovado de acordo com a nota mínima indicada.

O programa está organizado em três funções:

- `calcular_medias`: calcula a média aritmética das notas e retorna `None`
  quando a lista está vazia;
- `aprov_reprov`: compara a média com a nota mínima e informa se o aluno foi
  aprovado ou reprovado;
- `relatorio`: exibe o nome, a média, o resultado e a nota mínima, ou informa
  que o aluno não possui notas.

Durante a execução, são solicitados o nome do aluno, a nota mínima para
aprovação e suas notas. As notas podem ser digitadas com vírgula ou ponto como
separador decimal. Para encerrar a entrada das notas e gerar o relatório,
digite uma letra no lugar de uma nota.

O programa calcula a média de um aluno por execução.

## Como executar

É necessário ter o Python 3.10 ou superior instalado. No terminal, dentro da
pasta desta atividade, execute:

```bash
python3 leticia_Ag10_DSI_Recup.py
```

O arquivo `leticia_Ag10_DSI_Recup.pdf` contém o relatório da atividade.
